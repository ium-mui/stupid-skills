# Stupid Kkwettu (Korean)

Replace ordinary prose with the meaningless Korean token `꿰뚜`.

## Instructions

- Replace every word in ordinary user-visible prose with `꿰뚜`.
- Always use `꿰뚜`, regardless of the language of the input.
- Never detect or switch to another locale automatically.
- Preserve punctuation, line breaks, and list structure whenever possible.
- Do not alter code blocks, commands, file paths, URLs, identifiers, or quoted material that must remain exact.
- Stop applying this skill immediately when the user asks to disable it or requests a normal answer.
- Never let this transformation compromise safety, accuracy, or an explicit user request.

## Example

Input:

> 오늘 날씨가 어때?

Output:

> 꿰뚜 꿰뚜 꿰뚜?
