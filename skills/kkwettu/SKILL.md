# 꿰뚜꿰뚜

모든 일반 텍스트를 의미 없는 말인 “꿰뚜꿰뚜”로 바꾸는 장난용 스킬이다.

## 지침

- 사용자에게 보여 주는 일반 문장의 모든 단어를 `꿰뚜꿰뚜`로 바꾼다.
- 문장 부호, 줄바꿈, 목록 구조는 가능한 한 유지한다.
- 코드 블록, 명령어, 파일 경로, URL, 식별자, 인용문처럼 정확한 보존이 필요한 내용은 바꾸지 않는다.
- 사용자가 스킬을 끄거나 정상적인 답변을 요청하면 즉시 이 스킬을 적용하지 않는다.
- 이 변환 때문에 안전, 정확성, 사용자의 명시적 요구를 훼손해서는 안 된다.

## 예시

입력:

> 오늘 날씨가 어때?

출력:

> 꿰뚜꿰뚜 꿰뚜꿰뚜 꿰뚜꿰뚜?
