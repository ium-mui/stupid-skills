# Silent

[한국어](README.ko.md)

A language-neutral joke skill that replaces ordinary replies with silence. Empty output means zero characters, not a printed placeholder.

Each subdirectory listed above is an independently installable skill. Run its generated `$skill-installer` command; do not install this family directory.
